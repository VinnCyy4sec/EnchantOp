# EnchantOp Mod - Minecraft 1.21 Fabric

Mod EnchantOp menambahkan **15 enchantment custom** dengan **ability unik** ke Minecraft 1.21 menggunakan Fabric loader.

## Fitur Utama

### 15 Enchantment Custom:
1. **Fireball** - Luncurkan fireball ke musuh
2. **Lifesteal** - Heal saat menyerang
3. **Frost** - Membeku musuh
4. **Lightning** - Panggil petir
5. **Teleport** - Teleport ke musuh
6. **Sharpness Plus** - Extra damage
7. **Knockback Plus** - Knockback lebih besar
8. **Speed Boost** - Haste buff
9. **Bleeding** - Damage over time
10. **Vampire** - Drain health musuh
11. **Stun** - Paralisis target
12. **Fury** - Damage multiplier
13. **Reflection** - Reflect damage
14. **Curse** - Weaken enemy
15. **Explosive** - Create explosion

### Ability System:
- Tekan **SHIFT + Right-Click** dengan senjata berenchant untuk aktifkan ability
- Setiap enchantment memiliki ability unik dan cooldown
- Enchantment dapat di-combine pada satu weapon

### Enchant Books:
- Spawn otomatis di **loot chest** di Overworld, Nether, End
- 3 tier: Common, Uncommon, Rare
- Dapat diaplikasikan ke semua vanilla weapons

## Instalasi

1. Download Fabric Loader: https://fabricmc.net/use/
2. Download Fabric API untuk 1.21
3. Copy file mod ke folder `mods/`
4. Jalankan Minecraft

## Requirements

- Minecraft 1.21
- Fabric Loader 0.15.11+
- Fabric API 0.100.0+
- Java 21+

## Config

Mod tidak memerlukan config, langsung bisa digunakan!

## Kompatibilitas

Kompatibel dengan mod Fabric lainnya yang tidak konflict dengan enchantment system.
